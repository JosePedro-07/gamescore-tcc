# GameScore 🎮

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Desenvolvimento de Sistemas.

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## 📌 Objetivo
Desenvolver um site de avaliação e recomendação de jogos, permitindo aos usuários consultar notas, opiniões e recomendações.

## 📚 Status
Projeto acadêmico finalizado.
